# Code of conduct

We want this project to be a respectful, practical place to collaborate.

Be considerate, discuss ideas rather than people, assume good intent, and give
specific technical feedback. Harassment, discrimination, threats, doxxing, and
deliberate disruption are not acceptable.

Maintainers may edit or remove contributions and restrict participation when
behavior harms the community. For sensitive conduct reports, contact the
maintainer privately through the GitHub profile associated with this
repository. Do not put personal or sensitive details in a public issue.
